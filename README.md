# Mini Market - 3D Virtual Supermarket

Brauzerda ishlaydigan zamonaviy 3D supermarket ilovasi (Three.js, TypeScript va Vite).

## 🚀 Ishga tushirish yo'riqnomasi

Loyihani kompyuteringizda ishga tushirish uchun quyidagi buyruqlarni ketma-ket bajaring:

1. **Loyiha papkasiga o'ting:**
   ```bash
   cd "C:\Users\777 comp service\Desktop\mini market"
   ```

2. **Kutubxonalarni o'rnating:**
   ```bash
   npm install
   ```

3. **Dasturni ishlab chiquvchi (development) rejimida ishga tushiring:**
   ```bash
   npm run dev
   ```

4. Brauzeringiz avtomatik tarzda `http://localhost:3000` manzilini ochadi.

## 🎮 Boshqaruv (O'yin qoidalari)

- **Harakatlanish:** `W`, `A`, `S`, `D` yoki strelka tugmalari (`←`, `↑`, `→`, `↓`)
- **Atrofga qarash:** Ekranga bir marta bosib **Pointer Lock** rejimini yoqing va sichqonchani harakatlantiring
- **Mahsulotni savatga qo'shish:** 
  - Mahsulotga yaqinlashib unga qarang va ekranda chiquvchi **"🛒 Savatga qo'shish"** tugmasini bosing
  - Yoki klaviaturadagi `E` yoki `Enter` tugmasini bosing
- **Mobil boshqaruv:** Chap tomondagi virtual joystik orqali yuriladi, o'ng tomondagi sensorli barmoq orqali atrofga qaraladi va "Olish" tugmasi bosiladi.
- **Savat:** Chap pastda joylashgan, unda mahsulotlar sonini o'zgartirish, o'chirish va buyurtma berish mumkin. Ma'lumotlar avtomatik tarzda `localStorage` da saqlanadi.
